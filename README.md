# SGPA Calculator 🎓

A simple, responsive **SGPA (Semester Grade Point Average)** calculator created by **Academic Avengers**. This web-based tool allows students to input their subjects, credit hours, and grades to calculate their SGPA instantly.

## ✨ Features

- Add multiple subjects with credit hours and grades
- Grade point values based on standard university scales
- Responsive layout for mobile and desktop
- Easy-to-use UI
- Instant SGPA calculation
- Option to remove individual subjects

## 🧠 How to Use

1. Enter the **subject name**, **credit hours**, and **select grade**.
2. Click the **"Add"** button.
3. Once all subjects are entered, click **"Calculate SGPA"**.
4. View your SGPA result.
